STUDY PLANNER - DOCKER RUN INSTRUCTIONS

1. Install Docker Desktop and make sure Docker is running.
2. Open a terminal in the Study-Planner folder.
3. Run:

   docker compose up --build

4. Wait until client, server and mongo are healthy.
5. Open:

   http://localhost:8080

Backend health check:
   http://localhost:5000/api/health

Stop containers:
   docker compose down

Stop containers and delete Docker MongoDB test data:
   docker compose down -v

Optional: copy .env.example to .env and replace JWT_SECRET with your own long random secret before production use.
