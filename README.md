# StudyFlow Frontend

Responsive React + Vite + Tailwind CSS frontend for the Study Planner MERN application.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Default API URL:

```env
VITE_API_URL=http://localhost:5000/api
```

The backend should run on port 5000 and the Vite frontend on port 5173.
